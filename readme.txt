readme.txt - Activate: Canada's arcade
(1) 4 pages: index, games, locations, contact. Same h1 tag and a p tag of 4 nav links on every page.
(2) index: picture navigation based on Fig 2.7, 3 img inside a tags linking to the other pages. alt text names the page each image goes to.
(3) games: ul for games you can play, ol for how a visit works.
(4) locations: table with caption, thead, tbody. rowspan=2 merges ON for Mississauga and Pickering.
(5) contact: form method=post, action is a placeholder (no server code yet). Used text, password, radio (same name), checkbox, select, textarea, hidden, submit, reset.
(6) CSS: external style.css linked on all pages: dark background, link colours, hover, table borders; internal style on index for image border; inline style on submit button.
(7) Sources: photos, links and intro text from new.playactivate.com. Used an AI tutor to explain concepts and tags as well as CSS rules to enable me understand each line of code written.
